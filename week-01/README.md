# Week 01 — What makes these sites different?

## The idea

This week was about defining what actually makes the restaurant websites I am building different from a typical restaurant website.

Two things are central:

1. Self-service menu management — owners can update their own menu from a dashboard, with changes reflected on the site without requiring a developer.
2. Direct customer enquiries — enquiries go directly to the owner's inbox rather than through a third-party marketplace.

These aren't just features. They are architectural decisions that shape how the system is built.

## The artifact

The Ouu Lala demo is the artifact for Week 01.

The actual client implementation is currently private pending the owner's approval. This repository therefore documents the engineering work and decisions without exposing client-owned source code.

## What I learned

The biggest lesson this week was that a good product isn't defined only by the technology behind it.

The architecture should support what the user actually needs: less administrative work, fewer intermediaries, and more control for the business owner.

No source code is included this week because the client repository remains private.
